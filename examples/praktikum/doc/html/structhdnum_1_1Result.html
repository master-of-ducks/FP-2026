Detailed Description

Container for orthogonality and representation error metrics.

All fields use FP1024 (very high precision) so that errors computed from lower-precision experiments can be compared without loss of resolution.

Fields named ortho_err_* store the Frobenius norm of Q^T Q - I for the corresponding algorithm variant, while rep_err_* stores the relative representation error ||A - Q(Q^T A)||_F / ||A||_F.
