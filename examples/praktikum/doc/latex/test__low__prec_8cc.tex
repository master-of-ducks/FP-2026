\doxysubsection{Detailed Description}
Test suite to find the condition number at which different low precision runs fail. 

Previous experiments have shown, that orthogonalisations using FP8 or FP16 fail relatively early. This test suite is intended to finde the precise condition number for which the different implementations fail, using uniform precisions.
