\doxysubsection{Detailed Description}
Container for orthogonality and representation error metrics. 

All fields use {\ttfamily FP1024} (very high precision) so that errors computed from lower-\/precision experiments can be compared without loss of resolution.

Fields named {\ttfamily ortho\+\_\+err\+\_\+\texorpdfstring{$\ast$}{*}} store the Frobenius norm of {\ttfamily Q\texorpdfstring{$^\wedge$}{\string^}T Q -\/ I} for the corresponding algorithm variant, while {\ttfamily rep\+\_\+err\+\_\+\texorpdfstring{$\ast$}{*}} stores the relative representation error {\ttfamily \texorpdfstring{$\vert$}{|}\texorpdfstring{$\vert$}{|}A -\/ Q(\+Q\texorpdfstring{$^\wedge$}{\string^}\+T A)\texorpdfstring{$\vert$}{|}\texorpdfstring{$\vert$}{|}\+\_\+F /\+ \texorpdfstring{$\vert$}{|}\texorpdfstring{$\vert$}{|}\+A\texorpdfstring{$\vert$}{|}\texorpdfstring{$\vert$}{|}\+\_\+F}.
